## 学什么、怎样学

- 掌握网络的基本概念、体系结构和参考模型，理解各层协议的工作原理。
- 理解协议设计中的算法、资源共享和模块划分，能够解释“为什么这样设计”。
- 通过实验将协议、报文与程序行为联系起来。
- 课堂基本按自底向上的路线组织：**物理层 → 数据链路层 / MAC → 网络层 → 传输层 → 应用层**，另有网络安全等内容。

主教材为 *Computer Networks* 第 6 版（课件列 Tanenbaum / Wetherall）。课堂推荐对照 *Computer Networking: A Top-Down Approach*（Kurose / Ross）：前者自底向上，后者从应用向底层展开。课件与作业通过学在浙大提供。
